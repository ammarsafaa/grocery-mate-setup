# خطة إكمال نظام البقالة

## النتيجة المطلوبة
توسيع النظام الحالي ليشمل مجموعات اختيارية في نقطة البيع، مشتريات ومخزون متكاملين، طباعة حرارية قابلة للتخصيص، وتغيير ألوان النظام وخط أسماء المنتجات، مع بقاء البيانات محلية داخل نسخة Windows.

## 1. المجموعات ونقطة البيع
- إضافة شاشة لإدارة المجموعات: الاسم، الصورة أو الأيقونة، اللون، الترتيب، والتفعيل.
- ربط كل منتج بمجموعة، مع خيار «بدون مجموعة» للمنتجات غير المصنفة.
- إضافة مفتاح في الإعدادات لتشغيل أو تعطيل عرض المجموعات.
- عند التشغيل: تعرض نقطة البيع المجموعات أولاً، ثم منتجات المجموعة المختارة، مع زر للرجوع وكل المنتجات.
- عند التعطيل: تعرض نقطة البيع المنتجات مباشرة كما تعمل الآن.
- يبقى البحث بالاسم والباركود عاملاً في الحالتين.

## 2. المشتريات والمجهّزون
- إضافة إدارة المجهّزين وبياناتهم الأساسية.
- إضافة فاتورة شراء كاملة: المجهّز، رقم الفاتورة، التاريخ، المنتجات، الكمية، سعر الشراء، الإجمالي، المدفوع، والمتبقي.
- دعم المنتجات بالقطعة وبالكيلو داخل فاتورة الشراء.
- زيادة المخزون تلقائياً عند اعتماد فاتورة الشراء، وتسجيل حركة مستقلة لكل صنف.
- إضافة سجل فواتير المشتريات مع البحث، العرض، والطباعة.
- إضافة كشف حساب للمجهّز يوضح الفواتير والمدفوعات والرصيد المتبقي.
- منع تعديل الفاتورة المعتمدة بطريقة تفسد المخزون؛ الإلغاء أو التعديل ينشئ حركة عكسية واضحة.

## 3. المخزون
- إنشاء سجل حركات للمخزون: شراء، بيع، مرتجع، تسوية، وتلف.
- عرض الرصيد الحالي، سعر الشراء، قيمة المخزون، والحد الأدنى لكل منتج.
- تنبيه للمنتجات منخفضة أو نافدة المخزون.
- شاشة جرد لتصحيح الكمية مع حفظ السبب والمستخدم والتاريخ.
- تقارير حركة صنف، المشتريات، الأرباح التقديرية، والمنتجات منخفضة المخزون.

## 4. الطابعات والطباعة
- إضافة صفحة إعدادات تعرض الطابعات المثبتة في Windows وتسمح باختيار الطابعة الافتراضية.
- دعم ورق حراري بعرض 58 ملم و80 ملم، مع اختيار المقاس من الإعدادات.
- خيارات الطباعة التلقائية بعد البيع، عدد النسخ، القص التلقائي، وفتح درج النقد عند توفر الدعم من الطابعة.
- إضافة زر لطباعة نسخة تجريبية وزر لإعادة طباعة أي فاتورة محفوظة.
- في المعاينة داخل المتصفح ستتوفر معاينة الفاتورة، أما اختيار الطابعة والطباعة الصامتة فتعملان داخل نسخة Windows.

## 5. مصمم الفاتورة الكامل
- إضافة مساحة تصميم تحاكي عرض الورق المختار 58 أو 80 ملم.
- عناصر قابلة للسحب والإفلات وإعادة الترتيب: الشعار، اسم المتجر، العنوان، الهاتف، رقم الفاتورة، التاريخ، الكاشير، جدول المنتجات، الإجمالي، المدفوع، الباقي، الضريبة أو الخصم عند تفعيلهما، والرسالة الختامية.
- لكل عنصر: إظهار أو إخفاء، حجم الخط، نوع الخط، عريض، المحاذاة، المسافات، والخطوط الفاصلة.
- رفع شعار للفاتورة وتغيير حجمه ومحاذاته.
- توفير خطوط عربية مناسبة محفوظة مع البرنامج لتعمل دون إنترنت.
- معاينة مباشرة، استعادة التصميم الافتراضي، وحفظ تصميم مستقل لكل مقاس ورق.

## 6. مظهر النظام وخط المنتجات
- إضافة عدة ألوان جاهزة، ووضع فاتح أو داكن، مع اختيار لون رئيسي مخصص.
- تطبيق المظهر المختار على جميع الشاشات مع الحفاظ على وضوح النصوص.
- إضافة اختيار مستقل لخط أسماء المنتجات في نقطة البيع، مع عدة خطوط عربية وأحجام مناسبة.
- حفظ الخيارات في قاعدة البيانات وتطبيقها تلقائياً بعد إعادة تشغيل البرنامج.

## 7. سلامة البيانات والتوافق
- ترقية البيانات الحالية تلقائياً دون فقد المنتجات والصور والمبيعات والورديات والإعدادات.
- إدخال المجموعات والمشتريات والمجهّزين وحركات المخزون ضمن النسخ الاحتياطي والاسترجاع.
- إبقاء نسخة المتصفح للتجربة، مع اعتماد قاعدة SQLite في برنامج Windows.
- حماية صفحات المشتريات والمخزون والإعدادات بصلاحية المدير، مع إبقاء نقطة البيع للكاشير.

## ترتيب التنفيذ والاختبار
1. تحديث البيانات والمجموعات وإعدادات المظهر.
2. بناء المشتريات والمجهّزين وحركات المخزون والتقارير المرتبطة بها.
3. بناء إعدادات الطابعة ومصمم الفاتورة.
4. ربط إتمام البيع بالطباعة وتحديث المخزون، ثم اختبار المسارات كاملة.
5. اختبار نسخة Windows فعلياً للطابعة وSQLite والنسخ الاحتياطي والميزان.
6. بعد اكتمال الاختبارات فقط، تجهيز ملف التثبيت النهائي لويندوز 10 و11.

## تفاصيل تقنية
- سيبقى التخزين المحلي في SQLite داخل نسخة Windows، مع ترقية آمنة للبيانات القديمة.
- سيستخدم مصمم الفاتورة تمثيلاً منظماً للعناصر بدلاً من تخزين HTML حر، لتجنب تلف التصميم وتسهيل التوافق بين 58 و80 ملم.
- ستُطبع الفاتورة من نافذة طباعة داخلية مخصصة، مع قائمة الطابعات الموجودة على جهاز الكاشير.
- عنوان ميزان Rongta RLS1100 محفوظ كـ `192.168.1.87`، والمنفذ `3001` يبقى مؤقتاً وقابلاً للتغيير حتى اختباره على الجهاز الحقيقي.

## حدود هذه المرحلة
- لن يُجهّز ملف EXE النهائي قبل إتمام واختبار الوظائف أعلاه.
- دعم القص ودرج النقد يعتمد على تعريف الطابعة وإمكاناتها، لذلك سيُختبر على الطابعة الحقيقية.
