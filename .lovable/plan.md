# التحكم بحجم مربع المنتج نفسه

## التعديل المقترح
- تصحيح شريط الحجم الموجود في الإعدادات حتى يغيّر عرض وارتفاع مربع المنتج نفسه، مو الصورة وحدها.
- جعل مربعات المنتجات والمجموعات مربعة ومحددة بالحجم الذي تختاره، دون تمددها لملء عرض الصفحة.
- عند التصغير يظهر عدد أكبر من المربعات بالصف، وعند التكبير يقل عددها؛ يبقى الفراغ المتبقي خارج المربعات.
- ترتيب الصورة والاسم والسعر داخل الحجم المختار، مع الحفاظ على وضوح السعر ومنع تداخل المحتوى.
- إبقاء خيار خط اسم المنتج مستقلاً، وحفظ الحجم بالطريقة الحالية ليستمر بعد إعادة تشغيل البرنامج.
- لا تتغير طريقة البيع أو الأسعار أو الصوت أو اتصال الميزان والخادم.

## التحقق
- فحص الأبعاد الفعلية للمربعات عند أحجام صغيرة وكبيرة، وليس أبعاد الصورة فقط.
- فحص المنتجات والمجموعات مع الصور وبدونها، والأسماء الطويلة، وحفظ الحجم واستعادته.
- إذا منعت شاشة التفعيل الوصول لنقطة البيع، أوضح حدود التحقق؛ تجربة Windows تحتاج EXE محدثاً.

## تفاصيل تقنية
- استبدال أعمدة الشبكة المتمددة `1fr` بأعمدة محددة بخيار الحجم المحفوظ، وربط ارتفاع المربع بالخيار نفسه.
- إزالة الحد الأدنى الثابت للارتفاع والتنسيقات التي تسمح للمربع بالتمدد، وتنظيم المحتوى داخل أبعاده المحددة.
